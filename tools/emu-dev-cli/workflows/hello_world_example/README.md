# Hello World Example Workflow

An interactive, step-by-step example workflow demonstrating state persistence
and agent guidance.

## Usage

1. Initialize a new workflow session:
   ```bash
   emu-dev-cli workflow hello-world-example
   ```
2. Follow instructions using the generated state identifier:
   ```bash
   emu-dev-cli workflow hello-world-example --state=<unique-identifier>
   ```

# Git, Repo, and Gerrit Upload Playbook

**Role:** Operational Playbook  
**Location:** `hardware/google/aemu/tools/emu-dev-cli/docs/playbooks/git_and_gerrit.md`

## 1. Preventing `repo upload` / `git push` Hangs on Git-on-Borg

### Symptom

`repo upload` or `git push` hangs indefinitely during the `git fetch --negotiate-only` phase when
pushing to `https://googleplex-android.googlesource.com/...` because the superproject/repository
contains thousands of tags and refs.

### Fix

Always set `push.negotiate = false` in the repository before running `repo upload` or `git push`:

```bash
git config push.negotiate false
```

To apply across all repositories in the workspace:

```bash
repo forall -c 'git config push.negotiate false'
```

## 2. Git Commit Message Rules

Every commit message in `hardware/google/aemu`, `hardware/generic/goldfish`, and `external/qemu`
must follow these rules:

- **NEVER include `TAG=`, `CONV=`, `AGY=`, or `ORIGINAL_AUTHOR=` trailers.**
- Use Conventional Commit subjects (`feat(scope): ...`, `fix(scope): ...`, `refactor(scope): ...`,
  `docs(scope): ...`, `test(scope): ...`).
- Keep the subject line $\le 72$ characters.
- Include standard Gerrit trailers at the bottom:
  - `Bug: <id>`
  - `Test: <exact bazel test target or verification command>`
  - `Change-Id: I...` (automatically generated by Gerrit's `commit-msg` hook; never invent random
    Change-Ids).

## 3. Isolating Independent Fixes into Clean Branches

When a feature stack contains standalone bug fixes or test infrastructure fixes (e.g., TSAN
suppressions, flaky test fixes) that can land independently:

1. **Create a clean repo branch from `goog/emu-main-next`:**
   ```bash
   repo start <fix-branch-name> .
   ```
2. **Cherry-pick the target commit:**
   ```bash
   git cherry-pick <commit-sha>
   ```
3. **Verify and upload the standalone branch:**
   ```bash
   mise presubmit
   git config push.negotiate false
   repo upload --cbr -y -o "nokeycheck" .
   ```
4. **Return to the feature stack and drop the cherry-picked commit:**
   ```bash
   git checkout <feature-branch>
   git rebase --onto <commit-sha>^ <commit-sha> HEAD
   ```

## 4. Non-Interactive Gerrit Upload Flags

- **Upload for full presubmit + review:**
  ```bash
  git config push.negotiate false
  repo upload --cbr -y -o "nokeycheck" --label Presubmit-Ready+1 .
  ```
- **Upload as Work-In-Progress (WIP):**
  ```bash
  git config push.negotiate false
  repo upload --cbr -y --wip -o "nokeycheck" .
  ```
